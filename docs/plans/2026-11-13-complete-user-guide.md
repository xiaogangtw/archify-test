# 簡明圖像操作教學

## 範圍
依使用者要求進一步精簡文字並全面套用專案 Astryx 設計規範：
1. 大幅削減文字量：移除繁複冗長的敘述段落，功能益處收斂為單行 StatStrip 標籤，操作步驟精簡為一目了然的 1-2-3 動作徽章。
2. 套用 Astryx 規範樣式：採用 Astryx `SegmentedGroup` 分段導覽控制項、`StatusDot` 語意色彩、`Banner` 單一對齊線提示框、表面明度階梯（canvas -> surface -> surface-subtle -> surface-active）與標準 32px 控制項。
3. 強化圖片與視覺化操作：以純 CSS 與向量 SVG 繪製細緻的軟體介面 Mockup、游標點擊指示、步驟徽章與操作對照，保持零外部圖檔依賴。
4. 實戰教學建議：每一步提供濃縮為一句話的實戰提示（Pro-tip）。
