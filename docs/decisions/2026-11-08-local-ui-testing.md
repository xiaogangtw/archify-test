# 決策：畫面測試在獨立專案執行

日期：2026-11-08
狀態：已接受

## 背景
使用者要求 API／畫面報告分流，一般功能使用網頁，只有推播用 Android 模擬器。先前產品入口不提供裝置啟動；本次明確授權恢復本機環境啟動，但不恢復 VM 或舊 Control API。

## 決策
同一 Playwright Test runner 提供 API、web、android 專案；Android fixture 直接連到本機 Appium W3C session，不使用瀏覽器冒充 LINE。網站只啟動既有 AVD／Appium、保存截圖選項與選擇裝置，測試由獨立 CLI 執行。報告統一分類 JSON／HTML／純文字，截圖預設關閉，僅畫面 fixture 在開啟時擷取並附加受限 PNG 證據。

## 影響
不需要平台才能跑既有測試；環境、帳號與真實推播仍由使用者準備。舊報告與技能圖文格式保留歷史相容，日常新報告使用統一格式。裝置啟動不清除既有資料，網頁關閉不終止已啟動的本機測試環境。
