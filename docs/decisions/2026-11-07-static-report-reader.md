# 決策：測試專案獨立與靜態閱讀器

日期：2026-11-07
狀態：已取代

後續決策：[受限本機服務與獨立測試輸出](2026-11-07-local-workspace-service.md)。歷史理由保留如下。

## 背景
使用者不需要 VM、Git 連線或網頁內 Agent，希望使用自己的 AI 工具撰寫，無平台仍可 npm test 看報告。

## 決策
以 test-project 為獨立可複製的測試專案，包含框架、案例、skills 與可分享記憶。網頁只匯入產生的流程／報告 JSON，不建立業務 API 或資料庫。預設啟動只啟動靜態前端；報告另產生無腳本 HTML。

## 影響
移除現行入口對 VM、Git 與模型的依賴，保留舊程式及資料作遷移參照，不自動刪除或轉換。外部 AI 不受平台權限管理；skills 與 AGENTS.md 僅為協作約定。初版只提供 Node 邏輯／API 案例，Web／Android runner、來源掃描及舊報告遷移未整合。報告 hash 僅包含案例檔，不代表部署版本或完整可重現快照。
