# 決策：功能圖以依賴範圍增量分析

日期：2026-11-09
狀態：已接受

## 背景
每次來源更新都送完整圖給模型，重複分析成本高。已有逐檔 hash、靜態頁面依賴與固定功能 ID，可據此縮小範圍；只按修改行數或 mtime 判斷容易漏掉共用底層與設定變更。

## 決策
第一次完整建立基準；後續來源及知識未變時略過模型。以頁面依賴及既有功能為增量單位，平台保留範圍外功能、驗證局部提案並合併後驗證全圖。路由、解析設定、知識或無法確定影響範圍時完整分析。仍讀檔計算 hash，快取只重用同來源位置與相同 hash 的解析結果；不以 Git ref、mtime 或模型宣稱代替版本核對。

## 影響
主要降低模型輸入與重複推論，靜態掃描與安全檢查仍有成本，不承諾固定加速比例。舊專案需先完整建立一次基準；來源位置僅保存 hash。既有跨範圍關聯若證據異動則移除，等待後續更完整分析補充。案例、人工名稱、版本檢查與備份機制保留。完整契約見 [功能總覽](../frontend-feature-overview.md)。
