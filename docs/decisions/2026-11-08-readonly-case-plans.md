# 決策：流程頁僅閱讀，工作回到測試專案

日期：2026-11-08
狀態：已接受

## 背景
使用者希望流程頁只觀看表格，規劃與撰寫回到本機專案，先前的網站確認與複製任務增加操作負擔。本決策取代 [案例版本確認](2026-11-08-case-plan-review.md) 的強制確認及網頁編修流程。

## 決策
測試流程只顯示 catalog 的規劃、逐步預期、清理與問題，保留重新讀取及檔案位置。不顯示新增、編輯、確認、任務複製、狀態篩選或舊流程閱讀入口。本機 skills 在專案內規劃及實作，知識不足集中提問，不以網站確認作寫腳本前置條件。cases:check 預設只檢查資料完整性；--review 保留舊確認核對用途。

## 影響
不新增第二份案例來源，既有案例、腳本及確認檔不刪除。舊確認端點與歷史記錄保留相容，不出現在日常流程。產品測試的執行授權與清理要求不變。
