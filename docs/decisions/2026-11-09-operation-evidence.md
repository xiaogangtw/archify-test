# 決策：逐操作截圖與報告分卷

日期：2026-11-09
狀態：已接受

## 背景
結束畫面與大步驟截圖無法呈現每次操作；八張上限及整份內嵌容量不適合長流程。使用者要求每位使用者沿用相同行為。

## 決策
web-test 共用 fixture 包裝公開 Playwright 瀏覽器／頁面／Locator API 及畫面斷言，操作完成或失敗後留圖；支援自訂 context、角色與頁籤。截圖選項關閉仍不擷取。保留 JSON 內嵌及離線 HTML，超過現有單份容量時將同一案例證據分卷，明示分卷不是新案例，維持既有安全讀取界限。無圖或擷取失敗不得虛構證據。原生 Appium 維持明確 captureUi，不推定具備網頁包裝能力。

## 影響
無需逐一手寫操作截圖，既有使用共用 fixture 的腳本能升級；任意第三方物件或自行啟動瀏覽器不在保證範圍。報告數是分卷檔案數，不能當案例數；單張限制及安全讀取限制仍保留。需要合成真實瀏覽器驗證包裝相容性。


## 共用範本與網站隔離呈現

2026-11-10 接續決策：以使用者提供的圖文範本為現行視覺來源，網站及離線使用同一個純資料產生器。網站不直接讀取報告 HTML，從驗證 JSON 生成受 CSP 限制且不具同來源權限的 srcDoc；保留安全的內部放大腳本，避免兩套畫面漂移或讓任意歷史 HTML 取得平台權限。report token 由 Tailwind 設定生成獨立快照。操作就緒與回應等待使用結構化安全分類，不保留原始錯誤，舊資料不補造。
