# 決策：受限本機服務與獨立測試輸出

日期：2026-11-07
狀態：已接受

## 背景
使用者要求在地端網頁選擇前端來源、確認輸出位置、分析與產生單點 API 腳本，並以 .env 控制來源與報告資料夾。純靜態閱讀器無法完成受控本機檔案寫入。

本決策取代[純閱讀器決策](2026-11-07-static-report-reader.md)中無本機檔案服務的限制，其外部 AI、自行 Git 版控與獨立 CLI 原則保留。

## 決策
以 Vite dev／preview 同來源 middleware 提供限定目錄的 /local-api，重用純 AST 模組而不啟動舊 API／DB。平台 .env 設定來源與獨立測試專案，兩者互不包含，測試專案必須完全位於平台之外。生成以 exclusive create 保護既有檔，腳本預設停用，需有效資料與業務斷言後才可執行。

## 影響
使用者可在網頁完成掃描與生成，同時測試專案不依賴平台或解析器，能單獨 npm test 並 Git 版控。新增同源／session／路徑檢查與少量本機服務責任；純靜態部署沒有資料夾功能。不是 OS 沙箱，無法約束外部 AI 或同帳號惡意程序。動態來源、部署版本與真實產品驗收仍需額外證據。
