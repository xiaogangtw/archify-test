# 決策：初始設定允許受控 Git 下載
日期：2026-11-08
狀態：已接受

## 背景
使用者最新要求初始來源提供 Git／本機兩個選擇，取代過去完全沒有 Git 入口的限制。

## 決策
僅提供 clone 前端來源到使用者指定的新本機目錄；HTTPS／既有 SSH 認證，不收 token，不提供 push、pull、分支管理或版本部署。首次設定以全頁守衛阻止未完成時掛載產品頁，完成需有效來源、獨立框架與初步知識。（後續於 [2026-11-11-cli-setup-and-ai-toast.md](2026-11-11-cli-setup-and-ai-toast.md) 前置第 1 步 AI CLI 設定擴為四步。）

## 影響
增加本機 Git 依賴及失敗目錄處理；失敗不自動刪檔、不修改既有來源。下載不執行套件安裝、來源或模型，測試仍在獨立專案。
