# 決策：網站操作受控本機 CLI 分析

日期：2026-11-08
狀態：已接受

## 背景
使用者明確要求在網站發起 AI 功能分析及 MD／HTML 知識去重更新，取代先前複製任務到外部 AI 的主要流程。

## 決策
Vite 本機服務啟動 Codex exec，隔離工作目錄、read-only、停用 shell／unified exec、apps／browser／computer／multi-agent／skill search 與 web search；stdin 提供受限資料，模型只回傳 JSON。平台驗證提案、來源及知識／案例版本後套用；不讓模型直接刪改框架或腳本。JSONL 僅解析安全進度，原始輸出不進 UI 或日誌；取消／逾時終止程序樹。CLI 登入在使用者電腦，但推論仍使用其模型服務，不聲稱離線或完整 OS 隔離。

知識先以純 parser 抽出 HTML 文字，不渲染或載入資源。AI 依新文件合併重複、保留無關舊資訊、無法判定的衝突列問題。取代原檔先封存，沿用同主題 ID 或更新案例引用，可還原最近一次且未再次修改的 AI 更新。

## 影響
新增背景工作、狀態與取消，無資料庫；服務重啟後工作狀態不持久。模型登入、連線、耗時與語意正確性仍需核對，失敗不冒認成功。知識／目錄跨檔寫入不是 DB transaction，備份提供回復。這取代 [前端功能總覽決策](2026-11-08-frontend-feature-overview.md) 的「網站不啟動 CLI」部分，來源證據、非覆寫及未分配契約仍適用。
