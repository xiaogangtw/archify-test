# 決策：本機 AI 依來源證據整理功能總覽

日期：2026-11-08
狀態：已接受

## 背景
API 清單與測試關聯無法顯示尚無測試的產品功能。使用者要整個前端的功能總覽，同時保持 Agent 在本機工具、測試專案獨立版控。

## 決策
平台準備受限來源快照的路由、頁面、alias／相對 import、靜態可達 API、逐檔 hash 與增量差異。AI 讀 skill 及證據，輸出 proposal；驗證有效來源、固定 ID、所有已辨識頁面／API 的分配或明示未分配，來源及案例版本相符才備份合併。網站不啟動 CLI、模型或產品測試。

## 影響
總覽可顯示沒有測試的功能，產品頁面／API 關聯與測試流程分層。靜態可達不等同精確呼叫、導航路徑或業務覆蓋；parser 有限制，AI 推測必須明示。失去來源的功能保留 not-found 與人工案例，不靜默刪除。第三方畫圖 renderer 不是此取證／套用契約的必要條件。

## 部分取代

[網站受控本機 CLI 分析](2026-11-08-website-ai-analysis.md) 取代網站不啟動 CLI 的操作限制，來源／版本／提案驗證與保留人工資料仍適用。
