## 五步操作

1. 在網站設定工作區、放入知識並分析功能。
2. 在自己的 AI 工具開啟獨立測試專案，請 AI 使用 plan-test-cases 寫案例。
3. 案例看過後，請 AI 使用 implement-tests 寫腳本。
4. 先檢查型別與證據 fixture，核對環境與資料後執行指定測試。
5. 回網站重新讀取：測試流程看計畫、測試清單看狀態、測試報告看執行證據。

mock 預覽不表示真實產品已通過；合成頁面腳本只示範結構，不是真實登入實作。網站沒有測試執行入口。舊專案指令依其 package.json 為準。
