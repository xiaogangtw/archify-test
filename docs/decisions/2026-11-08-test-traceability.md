# 決策：分離業務依據、測試意圖與執行證據

日期：2026-11-08
狀態：已接受

## 背景
腳本、文件與地圖各自維護會漂移；只認腳本則可能把錯誤斷言當成業務規則。共用 API 改動不會改變 spec hash，舊通過結果不能代表新版。

## 決策
knowledge 保存業務依據，test-cases/catalog.json 保存固定功能／案例 ID、測試意圖與明確問題，tests 保存實作，reports 保存帶依賴 fingerprint 的執行證據。地圖是讀取時產生的關聯視圖，不是另寫一份流程。匯入、test.step 與案例 ID 都是靜態宣告，不聲稱條件分支已執行或語意一致。未知事項由人員與本機 AI 補充，無強制審批。

## 影響
外部專案可攜版控，網站可讀取及編修知識／案例，不編輯或執行腳本。新版報告與依賴不符顯示已變更，舊報告顯示版本未知；不保存環境秘密。完整部署版本、動態依賴與業務語意仍需另外核對。Archify 第三方 skill 可使用交接資料繪圖，此版不宣稱已串接其 renderer。
