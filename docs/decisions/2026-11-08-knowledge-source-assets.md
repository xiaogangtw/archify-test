# 決策：來源資產與知識文字分開保存

日期：2026-11-08
狀態：已接受

## 背景
使用者要求每份 10 MB 文件及圖片解析；直接放寬模型 prompt 與知識單檔限制會超出輸入容量，也失去原始證據。

## 決策
來源上限與整理文字分離：原始文件／圖片以內容 hash 保存於測試專案 knowledge/sources；有效知識仍採小型 Markdown，包含原始資產及分段來源關聯。大型資料逐段處理，現有知識以有界批次比對，最後一次驗證套用，未處理片段不得被略過。CLI 只附加本次已驗證圖片，不開啟工具或任意本機路徑。圖片辨識結果必須區分觀察、推測、無法確認及參考圖／實際畫面的用途未指定狀態。

## 影響
來源可一起 Git 版控，去重及還原不刪除原始證據。多次模型呼叫會增加時間與用量，取消或失敗不套用有效知識。跨檔案套用沿用封存恢復方式，不宣稱資料庫交易或精確像素辨識。
