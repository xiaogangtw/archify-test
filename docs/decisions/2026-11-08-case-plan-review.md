# 決策：案例規劃與腳本實作分工

日期：2026-11-08
狀態：已取代（強制確認及網站編修部分由 [唯讀流程頁](2026-11-08-readonly-case-plans.md) 取代，原資料契約保留相容）

## 背景
使用者要先以人可讀表格確認流程，再由本機 AI 撰寫測試；原流程閱讀器只呈現腳本宣告，無法做事前規劃。

## 決策
沿用 test-cases/catalog.json，新增 steps、cleanup 與 target 選填欄位，測試流程頁編修同一份案例。網站另保存案例／功能來源與相關知識指紋確認記錄；任一依據變更即待重新確認。規劃 skill 不自行確認，實作 skill 先使用唯讀 CLI 驗證確認狀態。既有流程 JSON 保留為腳本宣告閱讀工具。

## 影響
不重複維護每案例 YAML；舊案例相容但需補步驟才可確認。檔案可與測試專案一起版控，確認記錄不是身分簽章或 OS 權限防護。模型工作在使用者工具執行，網站不新增聊天與腳本生成控制。
