# 決策：單檔報告與完整歷史

日期：2026-11-10
狀態：已接受

## 背景
使用者要求每輪網頁執行合為一份易讀報告，解除歷史100份限制，並同步新專案範本。舊版多格式與分卷增加歷史列表負擔。

## 決策
同一執行按既有API／UI分類各產生一份HTML；網頁單輪只有一份。schemaVersion 1及全部PNG內嵌於application/json，執行快照原子替換更新同檔。服務只解析資料，不執行匯入HTML；純文字按需產生。保留舊JSON及分卷，不刪舊檔。歷史服務不截斷；畫面每次增加50筆並搜尋全部歷史。隱藏前置說明，準備操作及證據保留。

## 影響
離線只需一檔，圖片延遲載入但不省略證據。單檔512MB為明確資源邊界，超出回報失敗。歷史仍逐檔掃描，大量歷史有IO成本；不靜默截斷。平台、新專案範本及目前專案共用產生器契約；產品API、路由、守衛與DB不變。
