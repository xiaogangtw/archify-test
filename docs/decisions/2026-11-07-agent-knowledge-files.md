# 決策：獨立測試專案的檔案型 Agent 知識庫

日期：2026-11-07
狀態：已接受

## 背景
使用者希望首次開啟平台時依序選擇前端、獨立腳本位置與匯入知識；AI 仍使用自己電腦的工具，測試與知識一起版控。單靠瀏覽器的資料夾上傳無法取得可供本機產生器使用的絕對路徑。

## 決策
沿用受同源與 session 保護的本機 middleware，提供 Windows 原生資料夾選擇與手動絕對路徑備援。驗證兩目錄不重疊、非連結後才初始化；只更新平台 .env 的兩個路徑，不保存測試認證、不修改來源。網頁操作立即更新此服務設定；手動 .env 變更仍須重啟。

知識採 UTF-8 Markdown／純文字，存於獨立專案 knowledge/documents，index.json 管理清單與首次設定完成狀態；已有相容初始化或匯入資料時抑制自動引導，不要求使用者另按完成，仍可手動重開。AGENTS.md 與 knowledge/README.md 提供 AI 閱讀入口。README 管理區段之外保留人工文字；文件以 UUID 儲存，內容相同略過、封存保留原檔。原有 skills 與 memory 維持原位。

不建立模型通道、向量搜尋或自動訓練；AI 是否閱讀取決於使用者的工具，入口與規則不是 OS 權限限制。匯入文件屬參考資料，不覆蓋任務指示或自動執行。平台只以文字呈現內容。

## 影響
可離線查看、手動理解及獨立 Git 版控，AI 不依賴平台也能讀取。代價是文字文件需使用者選取閱讀，尚無 PDF／Word 擷取、自動同步來源、語意搜尋與自動上傳模型。匯入限每份 128 KB、每次 20 份及 1 MB、索引最多 500 份。提交前仍須審查秘密與個資。

檔案操作失敗會回報錯誤並保留已存在內容；跨多檔更新並非資料庫交易，孤立文件或封存可從專案檔案復原。原生選擇器限 Windows，其他系統使用絕對路徑輸入。程序環境變數仍優先於 .env，啟動時不應另外指定與 UI 不同的根目錄。
