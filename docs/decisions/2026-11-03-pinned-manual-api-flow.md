# 決策：人工固定版本 API 流程與 AI 計畫分開

日期：2026-11-03
狀態：已接受

## 背景
隔離 Playwright Runner 不可連線真實 API。既有 Agent API 工作禁止刪除，包括草稿保存，無法將人工已保存的登入／刪除案例轉成執行流程。不能開放模型自行產生刪除操作或放寬 Runner 網路隔離。

## 決策
提供人工指定固定 API 案例版本的轉換入口，服務逐筆核對專案、版本、來源操作及環境，僅保存既有 script 的新版本。人工之後明確執行時，由原伺服器 API 流程發送器處理；worker 再核對精確固定 request，AI 規劃的刪除禁令保持。

## 影響
保存不發送請求，舊腳本與執行歷史不改寫。人工執行固定刪除案例仍具有真實副作用；沿用使用者點選執行的授權，沒有自動重試。新端點需部署 Control API，沒有增加任意秘密或端點輸入能力。
